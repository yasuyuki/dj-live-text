# DJ Live Text

DJ配信中に、その場で書いた短文を好きなタイミングで見せるWindows向けアプリ。
操作窓と不透明な出力専用窓を分離し、通常のウィンドウ／画面領域キャプチャーで使います。
実行時にアカウント・クラウド・生成AI・配信ソフト専用プラグインは不要です。

**開発プレビューです。MVP完成ではありません。** Windows実機でのIME・DPI・キャプチャー、
Funkot実再生との連携、60分の連続稼働、模擬配信の受け入れは未確認です。
結果と未完了事項は [検証表](docs/VERIFICATION.md) を参照してください。

## Windowsで起動

ソースからの実行にはNode.js 24が必要です。repo rootのPowerShellで:

```powershell
npm ci
npx install-electron
npm start
```

Electron 44はbinaryの取得を明示的な `install-electron` で行います。
初回の依存取得にはネット接続が必要ですが、通常の文字表示はオフラインで動きます。
Windows以外の配布・動作保証は対象外です。

配布フォルダーを作成する場合:

```powershell
npm run package:win
```

`dist/DJ-Live-Text-win32-x64/DJ-Live-Text.exe` が入口です。フォルダー全体が必要です。
Windows CIでもテスト後に同フォルダーをartifactとして保存します。
これは未署名の開発プレビューで、Store登録・署名済みインストーラーは含みません。

## 操作

1. 下書きを入力。選択した文字を「強調」「色を適用」で整え、プレビューを確認します。
2. 「表示／置換」でその時点の内容を確定して送出。以後の下書き編集は送出へ漏れません。
3. 「進める」は出現途中なら即時完了、完了後なら次ブロックを追加。最終到達後は停止します。
4. 「消去」は直ちに空画面にし、演出・保留更新・ライブ入力を取り消します。下書きは残ります。

ライブ入力ONは、現在の下書きと以後の確定した編集を即時送出します。IME変換中は直前の
確定表示を保持します。OFFにすると最後の表示が残ります。演出の再実行はしません。
文章が最小24pxでも収まらない場合、手動送出は拒否、ライブ入力は最後の正常表示を保持します。
警告は操作窓だけに表示します。短く編集すれば復帰できます。

「出力と連携の設定」で幅・高さ・背景・表示先・フルスクリーンを変更できます。
サイズはWindowsの論理ピクセル（DIP）です。100%以外の表示倍率ではキャプチャーの物理ピクセル数と
一致しない場合があります。設定適用は安全のため消去を伴います。
通常の出力更新はフォーカスを奪いません。起動直後・出力を開き直した直後は必ず空画面です。

配信ソフトでは **DJ Live Text — Output** のクライアント領域を選択します。
操作窓はキャプチャー対象に含めません。実際の配信プレビューで文字・背景だけが入ることを確認します。
領域キャプチャーに重なったOS通知や別アプリは、本アプリから排除できません。

### 記法・GUI・ショートカット

| 属性 | 記法 | GUI | キー（Ctrl+Shift） |
|---|---|---|---|
| 強調 | `**文字**` | 強調 | B |
| 色 | `[cyan|文字]` | 色を選び「色を適用」 | C（色を順送りして適用） |
| 箇条書き | 行頭 `- ` | 箇条書き | U |
| 表示方式 | 先頭行 `@mode combined` | 表示 | M（順送り） |
| 演出 | 先頭行 `@effect impact` | 演出 | E（順送り） |
| 速度 | 先頭行 `@speed normal` | 速度 | R（順送り） |

色は `white / cyan / yellow / red`、表示方式は `instant / characters / blocks / combined`、
演出は `clean / glow / impact`、速度は `slow / normal / fast`。
設定行は本文より前に1行ずつ置きます。GUIも同じ記法を編集し、別の書式データは持ちません。
強調と色は `**[cyan|文字]**` または `[cyan|**文字**]` として併用できます。
任意HTML・CSS・画像・scriptは解釈しません。未完の記法は通常の文字として扱います。

空行でブロックを分けます。箇条書きは各項目が1ブロックです。
通常の単一改行は同じブロック内の改行です。文字送りの単位は `Intl.Segmenter` の書記素クラスタ。
書式境界に結合文字がある場合は、クラスタ先頭の書式を全体へ適用します。

| 操作 | キー |
|---|---|
| 表示／置換 | Ctrl+Enter |
| 進める | Ctrl+→ |
| 消去 | Ctrl+Backspace |
| ライブON/OFF | Ctrl+Shift+L |
| 曲紹介 | Ctrl+Shift+T |

主要キーは操作窓にフォーカスがある間だけ有効です。書式キーは下書き編集中のみ。
通常のEnter・Space・Escapeは送出しません。IME変換中の送出キーを無効化します。
**Ctrl+Backspaceは入力中・変換中も消去専用**です。単語削除には割り当てません。
GUI書式変更後はエディターへフォーカスを戻し、ネイティブUndo/Redoを保ちます。

### Funkot連携

[funkot-player](https://github.com/yasuyuki/funkot-player) だけを対象とします。
現行の公開版に、このアプリ向けAPIがあるとは想定しません。
必要な追加APIと候補の扱いは [設計メモ](docs/DESIGN.md) に記載しています。
連携ポート0はOFF。接続できない間も通常の文章送出・消去は使えます。
曲情報は候補欄に届くだけで、曲紹介を押すまで送出しません。
手動送出後は曲が変わっても表示を保ちます。曲紹介はライブ入力をOFFにし、下書きを保持します。
未接続・未取得・停止中の候補は新規送出できません。手入力で紹介する場合は下書きを使います。

下書きと基本設定はElectronのユーザーデータ領域の `settings.json` に保存します。
Windowsの通常配置は `%APPDATA%/dj-live-text/`。送出内容とライブON状態は保存しません。

## 開発・検証

```powershell
npm test
npx playwright install chromium
npm run test:ui
```

Nodeテストは文章・進行・競合・保存・HTTP読取契約を検証します。
Playwrightは実DOMで書式操作・日本語を含む文字の配置・溢れ・Undoを検証します。
Windowsでは追加で実Electronの2窓・送出・閉鎖・再起動を検証します。
合成compositionイベントの試験は、日本語IME実機試験の代替ではありません。
